# Security Policy

## Supported versions

Security fixes are currently provided for the latest beta release only.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues or pull requests. Use GitHub's **Report a vulnerability** option in the repository's Security tab to send a private advisory to the maintainer. Include the affected version, steps to reproduce, impact, and any suggested mitigation.

If private vulnerability reporting is unavailable, contact the repository owner privately through GitHub and do not publish exploit details before a fix is available.

The maintainer will acknowledge a report when possible, investigate it, and coordinate a fix and public disclosure with the reporter.
