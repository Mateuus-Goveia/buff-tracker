# Code of Conduct

Everyone participating in this project is expected to make the community welcoming and respectful.

## Our standards

Examples of positive behavior include being considerate, giving constructive feedback, accepting corrections gracefully, and focusing criticism on ideas and code.

Unacceptable behavior includes harassment, insults, discrimination, sexualized language or imagery, threats, doxxing, and repeated disruption of discussions.

## Maintainer responsibilities

Project maintainers may edit, reject, or remove contributions that violate this code and may block people from participating when needed. Maintainers will explain moderation decisions when practical.

## Reporting

Do not report conduct concerns in a public issue. Contact the repository owner privately through GitHub. Include links or details needed to understand the concern, and avoid sharing other people's private information publicly.

This code applies to project spaces and public interactions where someone represents the project.
