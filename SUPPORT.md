# Support

- **Bug reports:** open a GitHub issue using the Bug report template. Include the app version, Windows version, input mode, steps to reproduce, and expected versus actual behavior. Remove personal information from screenshots and logs.
- **Feature ideas:** open a Feature request issue and explain the use case.
- **Usage questions:** check the README first, then open a GitHub issue with the `question` label.
- **Security concerns:** follow `SECURITY.md`; do not post them publicly.

This project is maintained in spare time. There is no guaranteed response time or support for unofficial builds.
